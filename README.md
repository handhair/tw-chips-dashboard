# 台股籌碼前兆儀表板

用臺灣證券交易所、臺灣期貨交易所的每日盤後資料，追蹤台股崩跌前常出現的籌碼訊號：

- 外資台指期淨未平倉（淨空單）
- 外資現貨 20 日累計買賣超
- 融資餘額，以及融資增幅是否快過指數漲幅
- 小台散戶多空比
- 量能倍數

網頁上有六個訊號的燈號、每週燈號熱圖、2026 年 7 月與 10–11 月兩次下跌以高點對齊的對照圖，以及每日走勢。

> 警戒門檻是回頭看這兩次下跌訂的，有後見之明，只代表風險累積程度。這不是投資建議。

## 檔案

| 檔案 | 用途 |
|---|---|
| `index.html` | 儀表板網頁（GitHub Pages 直接發布這個檔案） |
| `data/chips_data.json` | 每日籌碼資料，網頁讀這個檔案 |
| `chips.py` | 從證交所、期交所抓資料，寫進 `data/chips_data.json` |
| `.github/workflows/update.yml` | 每個交易日自動更新資料並重新發布 |

## 第一次設定 GitHub Pages

1. 把這個資料夾推到 GitHub 的**公開**儲存庫
2. 到儲存庫的 **Settings → Pages**，**Source** 選 **GitHub Actions**
3. 到 **Actions → 更新籌碼資料並發布 → Run workflow** 手動跑一次
4. 跑完後網址會是 `https://<你的帳號>.github.io/<儲存庫名稱>/`

之後每週一到週五台灣時間下午 5:30 左右會自動更新（GitHub 排程可能晚 5～30 分鐘）。

## 在自己電腦上更新或預覽

只需要 Python 3.13 以上，不用安裝其他套件。

```
python chips.py                    # 只補抓還沒有的交易日
python chips.py --full 2026-02-01  # 從指定日期整段重抓（約 15 分鐘）
python -m http.server 8000         # 開 http://localhost:8000 預覽網頁
```

網頁要透過網址開（上面的 http.server 或 GitHub Pages），直接雙擊 `index.html` 會讀不到資料檔。

| 選擇權 Put/Call Ratio | 期交所「臺指選擇權 Put/Call Ratio」 |
